# 🎓 Student Performance & Risk Analyzer

## 📌 Project Overview

The **Student Performance & Risk Analyzer** is a beginner-friendly Machine Learning project that predicts a student's final marks based on academic and lifestyle factors.

The project also analyzes the student's performance level, identifies their risk level, and provides a personalized suggestion for improvement.

## 🎯 Objective

The main objective of this project is to demonstrate how Machine Learning can be used to analyze student data and provide useful academic insights.

## 📊 Input Features

The model uses the following information:

* Study Hours
* Attendance (%)
* Previous Marks
* Assignment Score
* Sleep Hours

## 🤖 Machine Learning Model

**Linear Regression** is used to predict the student's final marks.

The project follows these main steps:

1. Create and prepare the dataset
2. Select features and target
3. Split data into training and testing sets
4. Train the Linear Regression model
5. Predict final marks
6. Evaluate the model using Mean Absolute Error
7. Analyze performance and risk
8. Generate a personalized suggestion

## 📈 Results

The model achieved a Mean Absolute Error (MAE) of approximately **0.49** on the practice dataset.

> **Note:** The dataset contains only 15 manually created records for educational purposes. Therefore, this result should not be considered representative of real-world model performance.

## 💻 Interactive Interface

A **Gradio** interface was created where users can enter student information and receive:

* Predicted Final Marks
* Performance Level
* Risk Level
* Personalized Suggestion
